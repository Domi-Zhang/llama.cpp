## 1. 依赖准备（首次）

```bash
sudo apt update
sudo apt install git cmake ninja-build build-essential   # 基础
sudo apt install ccache                                   # 增量编译加速（可选但推荐）
# 若要用真实模型跑，建议装 curl（llama-server 下载模型用）
```

WSL 环境说明：本机是 x86_64，CPU 后端 + 可选 Vulkan/CUDA。Metal 只用于 macOS，本机不适用。

## 2. 构建（CMake）

### 最简 CPU 版
```bash
cmake -B build                                    # 生成（默认 CPU 后端）
cmake --build build -j $(nproc)                   # 编译，并行
```

### 常用构建选项（`-D` 追加在 `cmake -B` 后）

| 选项 | 作用 | 例 |
|---|---|---|
| `GGML_NATIVE=ON` | 针对本机 CPU 指令优化（AVX2 等） | 默认开 |
| `GGML_VULKAN=ON` | Vulkan GPU 后端 | 本机已开 |
| `GGML_CUDA=ON` | NVIDIA CUDA 后端 | 需装 CUDA 工具链 |
| `GGML_OPENMP=ON` | 多核 CPU 并行 | 默认开 |
| `LLAMA_CURL=ON` | 支持从 HF 下载模型 | 推荐 |
| `CMAKE_BUILD_TYPE=Debug` | 调试构建（关优化，可 gdb） | 开发时用 |
| `CMAKE_BUILD_TYPE=RelWithDebInfo` | 优化+调试符号 | 折中 |

### 用 CMake Preset（推荐，仓库自带）
```bash
cmake --preset x64-linux-gcc-release    # 见 CMakePresets.json
cmake --build build-x64-linux-gcc-release -j $(nproc)
```

### 增量 / 常用循环
```bash
cmake --build build -j $(nproc)          # 改代码后重编（ccache 会加速）
```

## 3. 运行 llama-cli（命令行对话）

```bash
# 用本地模型
./build/bin/llama-cli -m models/qwen2.5-0.5b-instruct-q4_k_m.gguf -p "你好，介绍一下你自己"

# 指定上下文/线程/生成参数
./build/bin/llama-cli -m models/qwen2.5-0.5b-instruct-q4_k_m.gguf \
    -c 2048 --threads 8 -n 128 -p "1+1=?"

# 开启交互式对话（敲入后回车，Ctrl+C 退出）
./build/bin/llama-cli -m models/qwen2.5-0.5b-instruct-q4_k_m.gguf -cnv
```

常用参数：`-m` 模型、`-p` prompt、`-n` 生成 token 数、`-c` 上下文长度、`--threads` 线程数、`-cnv` 对话模式、`--temp` 温度。

## 4. 运行 llama-server（HTTP API）

```bash
./build/bin/llama-server -m models/qwen2.5-0.5b-instruct-q4_k_m.gguf \
    -c 4096 --port 8080
# 另一终端：
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}]}'
```

- 默认 OpenAI 兼容端点：`/v1/chat/completions`、`/v1/embeddings`
- 流式：请求体加 `"stream": true`（SSE）
- 健康检查：`curl http://localhost:8080/health`；槽位状态：`/slots`
- 完整用法见 `tools/server/README.md`

## 5. 快速跑通（不重新编译）

仓库已经编好，直接跑：
```bash
# 小模型对话
./build/bin/llama-cli -m models/qwen2.5-0.5b-instruct-q4_k_m.gguf -p "你好"

# 起 server
./build/bin/llama-server -m models/qwen2.5-0.5b-instruct-q4_k_m.gguf -c 4096 --port 8080
```
如果 `build/` 里缺某个目标、或改了源码，回到第 2 节重新 `cmake --build build`。

## 6. 获取 / 转换更多模型

- 直接下载 GGUF（HF 上社区已转好）：
  ```bash
  ./build/bin/llama-server -hf ggml-org/gemma-3-1b-it-GGUF   # 需 LLAMA_CURL
  ```
- 从 HF safetensors 转 GGUF（见 `08-模型转换链`）：
  ```bash
  python3 -m pip install -r requirements.txt
  python3 convert_hf_to_gguf.py <hf模型目录>    # 缺省转 f16
  python3 convert_hf_to_gguf.py <目录> -o q8_0  # 转 q8_0 量化
  ```

## 8. 常见问题速查

| 现象 | 处理 |
|---|---|
| 编译报找不到 cmake/ninja | `sudo apt install cmake ninja-build` |
| 内存不足编译卡死 | `-j` 调小，如 `-j 4` |
| 7B 模型加载慢/内存不够 | 换小模型或减小 `-c` |
| WSL 里 GPU 不可见 | 默认走 CPU 已够用；Vulkan 需宿主机装驱动 |
| server 端口被占 | `--port <其他>` |
